2. 교사용 페이지 여는 방법

연구소 프로그램 폴더 안의 서버_시작.bat 파일을 더블클릭하세요. 검은 창(서버)이 뜨고 자동으로 브라우저가 열립니다. 이 검은 창을 닫으면 서버도 함께 꺼지고, 교사용 페이지 접속이 안 됩니다. 작업이 끝나기 전까지는 그대로 켜두세요.

맨 위 교사 비밀번호 칸에 미리 정해둔 교사 비밀번호를 입력해야 학생 계정 관리·게시판 답변· 연구동 설정 저장이 됩니다.

3. 문제 수정하기

왼쪽에서 단원을 골라 문제를 고친 뒤 💾 저장을 누르세요.

  • 로컬 파일 저장과 동시에, 자동으로 깃허브에도 반영됩니다(별도 조작 불필요).
  • 학생용 배포 사이트에는 저장 후 약 1분 뒤부터 반영됩니다. 저장하자마자 학생 화면을 새로고침하면 아직 예전 내용이 보일 수 있어요.
  • 저장 상태 메시지에 "깃허브에도 자동으로 반영했어요"가 뜨면 정상적으로 처리된 것입니다. 만약 "깃허브 반영에 실패했어요"가 뜨면(인터넷 연결 문제 등) 로컬 학생(이 컴퓨터로 접속한 학생)에게는 이미 반영됐지만 배포 사이트에는 아직 안 올라간 상태이니, 인터넷 연결을 확인하고 다시 저장해보세요.

4. 학생 계정 관리

명단 등록: "이름,학번" 형식으로 한 줄씩 붙여넣고 등록하면 계정이 만들어집니다. 이미 등록된 이름은 건드리지 않으니, 새 학생이 생기면 그때마다 다시 붙여넣어도 안전합니다.

비밀번호 초기화: 학생이 비밀번호를 잊어버리면 목록에서 "🔑 비번 초기화"를 누르세요. 다음 로그인 때 학번으로 로그인하고 새 비밀번호를 다시 정하게 됩니다.

연구포인트 · 특별연구포인트 조절: 같은 화면 아래쪽 표에서 학생별 현재 잔액을 보고, 지급·차감량을 입력해 "반영"을 누르면 됩니다. 즉시 반영이 아니라 그 학생이 다음에 로그인할 때 자동으로 적용됩니다.

5. 연구동 공개 설정

연구동(단원 묶음)을 열고 닫거나 마감일을 정할 수 있습니다. 마감일이 지나도 자동으로 잠기지는 않고 안내만 표시되니, 실제로 막으려면 직접 "닫힘"으로 바꿔야 합니다.
